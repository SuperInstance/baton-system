## Growth Mechanisms

### 1. Competitive Riffing (agent-riff v1→v2→v3→...)
Two agents build competing implementations. The winner's output becomes the baseline for the next round. Surprise and quality compound across generations.

### 2. Fleet Awareness (I2I protocol)
Every new crate that's useful gets registered with nebula and gets an I2I vessel. The fleet grows by accretion — each new capability makes every other capability more valuable.

### 3. GPU Acceleration (ternary-cuda-kernels v1→v2→...)
Music cognition patterns compiled to PTX. Each generation adds new kernels. The CPU reference implementation validates correctness. The GPU version runs at fleet scale.

### 4. Cross-Generation Learning (RiffMemory)
Each riff generation inherits accumulated knowledge from all previous generations. By generation N, the system has N-1 generations of data about what works.

### 5. Documentation Compounds (Loom's template)
Every crate gets PLUG_AND_PLAY.md. Every crate gets registered. Every crate gets a nebula reflex. The documentation is the discovery surface.
